Estructura del Proyecto — Matacos Deportes

Proyecto: Sistema Integral de Gestión, Punto de Venta (POS) Offline y E-commerce.
Comercio: Saavedra 241, Formosa Capital.

Propósito: Este documento detalla la distribución de carpetas del proyecto y justifica su diseño de forma simple para facilitar su inclusión en la documentación técnica y funcional.

2. Justificación y Explicación de Cada Carpeta

src/ (Código Fuente Principal)

Es la carpeta central donde vive todo el funcionamiento del sistema:

  • app/: Contiene las páginas y pantallas visibles para el usuario mediante Next.js 15.
    • admin/: Pantalla de administración para consultar stock, catálogo, proveedores y cambios masivos de precio.
    • pos/: Pantalla rápida para el mostrador de ventas, incluyendo la plantilla especial para imprimir tickets térmicos de 80mm y 58mm.
    • api/: Enlaces internos que responden datos en formato JSON para búsquedas rápidas de productos, alertas de stock y subida de fotos.
  • components/dashboard/: Los bloques visuales con los que interactúa el usuario (botones, tablas de stock, tarjetas de métricas y ventanas emergentes como la carga masiva de Excel o ajustes manuales).
  • server/: El "cerebro" del sistema que se ejecuta de forma segura en el servidor:
    • actions/: Acciones que guardan ventas o descuentan stock asegurando que si ocurre un corte de luz o error a mitad de camino, la base de datos no quede corrupta ni con stock negativo.
    • services/: Módulos para cálculos específicos, como apertura/cierre de turnos de caja y cálculo de comprobantes fiscales.
  • schemas/: Reglas escritas con Zod para garantizar que ningún dato llegue vacío o con formato erróneo (por ejemplo: que un precio siempre sea un número positivo o que un código de barras sea válido).
  • lib/: Herramientas auxiliares y conexiones:
    • dexie.ts: Base de datos local que guarda las ventas en la computadora de mostrador si se corta internet (enfoque Offline-First).
    • prisma.ts: Conexión con la base de datos principal PostgreSQL.
    • utils.ts: Funciones comunes, como dar formato de moneda en pesos argentinos ($ 45.000,00) y manejar la hora oficial de Argentina.
  • config/ y types/: Datos fijos del negocio (nombre del local, CUIT, dirección Saavedra 241) y definiciones técnicas para que el código sea seguro y ordenado.

prisma/ (Base de Datos)

Administra la estructura de la base de datos PostgreSQL:

  • schema.prisma: El plano donde se definen las tablas (productos, variantes por talle/color, ventas, movimientos de stock y cajas).
  • migrations/: El historial registrado de cada cambio hecho en las tablas de la base de datos a lo largo del tiempo.
  • seed.ts: Datos iniciales para que el sistema empiece a funcionar con categorías y configuraciones de prueba.

public/ (Archivos Estáticos y Multimedia)

Almacena los recursos que no cambian o que se muestran directamente en pantalla:

  • uploads/products/: Carpeta donde se guardan las fotografías de los productos y zapatillas subidas por los usuarios.
  • Logos y plantillas: El logo oficial de Matacos Deportes y las planillas Excel oficiales de carga de stock descargables.

scripts/ (Pruebas y Mantenimiento)

Herramientas automáticas para el equipo técnico:

  • Permiten probar que las ventas, los descuentos, el código de barras y el inventario funcionen correctamente sin tener que probar todo a mano en la pantalla cada vez que se hace un cambio.

contexto/ y docs/ (Documentación y Requerimientos)

Respaldan el trabajo académico y operativo del proyecto:

  • contexto/: Requisitos solicitados por el dueño del comercio, actas de reuniones y análisis de arquitectura.
  • docs/: Manuales de uso sencillos para los empleados del local y guías paso a paso para instalar o reparar el sistema en caso de cambiar de computadora.

Archivos en la Raíz (Infraestructura y Ejecución)

  • docker-compose.yml y Dockerfile: Permiten que el sistema y su base de datos arranquen en cualquier computadora de manera idéntica y aislada sin instalaciones complicadas.
  • iniciar-sistema.bat: Acceso directo para que el personal de mostrador pueda encender todo el sistema con un solo doble clic en Windows.
