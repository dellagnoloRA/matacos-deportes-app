Flujo de Inicio de Sesión, Validación de Middleware y Doble Guardia Server Actions

Secuencia completa desde el ingreso de credenciales (identificador dual), sellado de cookie HttpOnly de 12h, verificación en Next.js Middleware y censura de datos sensibles en el servidor.

sequenceDiagram autonumber actor Empleado as Empleado (Local Saavedra 241) participant UI as Navegador / Vista Login participant MW as Middleware (Next.js) participant Action as authActions.ts (loginAction) participant DB as PostgreSQL (Prisma) participant ServerAct as Server Actions Protegidas Empleado->>UI: Ingresa usuario ('cajero1' o correo) + contraseña UI->>Action: loginAction({ identifier, password }) Action->>DB: Busca en User por (username == id OR email == id) + includes Profile y Parent DB-->>Action: Retorna User + Hash + Perfil + Permisos Action->>Action: bcrypt.compare(password, user.password) alt Contraseña inválida o inactivo Action-->>UI: Retorna { success: false, error: "Credenciales inválidas" } else Contraseña válida Action->>Action: Resuelve permisos (Directos + Heredados del ParentProfile) Action->>Action: Firma JWT con jose (HS256, 12h) Action->>UI: Setea Cookie 'matacos_session' (HttpOnly, SameSite=Lax, MaxAge=12h) UI->>MW: Petición a ruta protegida (/admin o /pos) MW->>MW: jwtVerify(token, JWT_SECRET) alt Token válido MW-->>UI: Permite renderizado de la ruta UI->>ServerAct: getDetailedInventoryProducts() o listCashShifts() ServerAct->>ServerAct: hasPermission("inventario.costos" / "caja.auditoria_historial") alt No tiene permiso ServerAct-->>UI: Retorna datos censurados (costPrice: null) o Error 403 else Tiene permiso ServerAct-->>UI: Retorna datos completos con costos / arqueos end else Token inválido o corrupto MW->>UI: Elimina cookie corrupta y redirige a /login?redirect=... end end
