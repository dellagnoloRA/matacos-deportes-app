PARTE 1: Checklist de Preparación Pre-Desarrollo (Gestión y Negocio)

Insumos, acuerdos y definiciones de negocio indispensables antes de comenzar la programación:

1️⃣ Paso 1: Entrevista de Elicitación y Validación con el Cliente

Completar la reunión presencial en Saavedra 241 utilizando la guía de elicitación elaborada.

  • ☐ Inventario inicial: Definir si cerrarán un fin de semana para contar o si cargarán de forma progresiva por marcas.
  • ☐ Códigos de barra: Confirmar si los productos traen código de fábrica (EAN-13) o si se generarán códigos internos.
  • ☐ Fotografías: Acordar quién sacará las fotos de calzados/indumentaria para la tienda online.
  • ☐ Aspectos Fiscales: Confirmar condición ante AFIP/ARCA (Monotributo / Responsable Inscripto).
2️⃣ Paso 2: Recopilación de Activos de Marca (Branding Assets)

Solicitar una carpeta en Google Drive con los siguientes materiales:

  • ☐ Logotipo: Vectorial (SVG/AI) o PNG transparente en alta resolución.
  • ☐ Fotos del Local: Fachada de Saavedra 241, salón de ventas y equipo (sección «Quiénes Somos»).
  • ☐ Paleta de Colores: Colores primarios y secundarios para configurar Tailwind CSS.
  • ☐ Canales Oficiales: Número de WhatsApp comercial y redes sociales.
3️⃣ Paso 3: Plantilla de Productos de Prueba (Seed Data)

Entregar una planilla en Google Sheets para que carguen entre 20 y 50 productos reales:

Producto Marca Disciplina Talle Color Código EAN Costo Precio Stock
Zapatillas Gondor Topper Running 41 Negro 7791234567890 $ 35.000 $ 65.000 4
Camiseta Titular Umbro Fútbol L Azul 7799876543210 $ 22.000 $ 42.000 8
💡 Estos datos permitirán probar el buscador del mostrador (POS) y el carrito con productos reales desde la primera semana.
4️⃣ Paso 4: Cuentas y Credenciales de Terceros
  • ☐ Mercado Pago Developers: Crear app en developers.mercadopago.com.ar y obtener credenciales de prueba.
  • ☐ Dominio Web: Registrar matacosdeportes.com.ar (NIC Argentina).
  • ☐ AFIP / ARCA (si aplica): Certificado de pruebas (Homologación WSFE).
  • ☐ Servidor VPS: Cuenta creada en Hetzner, DigitalOcean o DonWeb.
5️⃣ Paso 5: Tablero de Tareas y Repositorio Git
  • ☐ Repositorio Git creado en GitHub/GitLab con el equipo invitado.
  • ☐ Tablero Kanban configurado con los 4 Sprints del roadmap.
PARTE 2: Configuración Técnica del Entorno (Dev Setup)

Paso a paso para preparar la máquina del desarrollador y comenzar a codificar:

1. Herramientas y Extensiones del Editor

A. Habilitar PNPM de forma nativa:
corepack enable corepack prepare pnpm@latest --activate
B. Extensiones recomendadas en VS Code / Cursor:
  • Prisma: Formateo y autocompletado del schema.prisma.
  • Tailwind CSS IntelliSense: Autocompletado de clases visuales.
  • ESLint & Prettier: Formateo automático de código al guardar (Ctrl + S).
  • Error Lens: Muestra errores de TypeScript directamente en la línea.
  • Docker: Monitoreo visual de PostgreSQL.

2. Estructura de Carpetas Recomendada (Next.js 15 App Router)

matacos-app/ ├── prisma/ │ ├── schema.prisma # Definición de tablas y relaciones │ └── seed.ts # Carga de productos de prueba ├── src/ │ ├── app/ │ │ ├── (ecommerce)/ # Rutas públicas (Home, Catálogo, Producto, Carrito) │ │ ├── (dashboard)/ # Rutas privadas (/pos mostrador, /stock, /caja) │ │ └── api/webhooks/ # Webhooks de Mercado Pago │ ├── components/ │ │ ├── ui/ # Componentes base shadcn (Button, Dialog, Table) │ │ ├── pos/ # Componentes exclusivos mostrador (Scanner, Ticket) │ │ └── ecommerce/ # Componentes web (ProductCard, Navbar) │ ├── lib/ │ │ ├── prisma.ts # Cliente singleton BD │ │ ├── mercadopago.ts # SDK Mercado Pago │ │ └── utils.ts # Formateador moneda ARS ($ 45.000,00) y fechas │ ├── server/actions/ # Lógica de negocio (crearVenta, descontarStock) │ └── schemas/ # Validaciones Zod compartidas ├── docker-compose.yml └── .env

3. Comandos del "Día 1" (Paso a Paso del Programador)

# 1. Crear el proyecto con Next.js 15, TypeScript y pnpm pnpm create next-app matacos-app --typescript --tailwind --eslint --app --src-dir # 2. Entrar a la carpeta del proyecto cd matacos-app # 3. Inicializar componentes de UI shadcn pnpm dlx shadcn@latest init # 4. Instalar librerías principales de backend, pagos y UI pnpm add @prisma/client mercadopago zod zustand dexie @tanstack/react-query lucide-react clsx tailwind-merge # 5. Instalar dependencias de desarrollo y Prisma pnpm add -D prisma tsx # 6. Levantar la base de datos PostgreSQL con Docker docker compose up -d postgres # 7. Inicializar Prisma y sincronizar el modelo de base de datos pnpm prisma init pnpm prisma db push # 8. Abrir el gestor visual de base de datos en el navegador pnpm prisma studio
