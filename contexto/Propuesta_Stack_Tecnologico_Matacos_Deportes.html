1. Detalle de Arquitectura por Capas

A. Frontend (Tienda Online + Punto de Venta)

Se utiliza Next.js 15 con App Router para resolver dos perfiles de uso en una sola base de código:

  • E-commerce Público: Renderizado del lado del servidor (Server Components / SSR) para garantizar tiempos de carga inferiores a 1 segundo en teléfonos móviles y posicionamiento SEO óptimo.
  • Punto de Venta Mostrador (/pos): Interfaz cliente ultra reactiva, optimizada para atajos de teclado, navegación sin mouse y lectura instantánea de códigos de barra.
  • Diseño con shadcn/ui + Tailwind CSS: Componentes accesibles, minimalistas y sin sobrecarga de librerías externas pesadas.
  • Modo Offline-First con Dexie.js: El catálogo se cachea en la base de datos local del navegador (IndexedDB) para que el mostrador pueda seguir cobrando si se corta internet.

B. Backend y Lógica de Negocio (TypeScript + Node.js)

El backend corre en TypeScript sobre Node.js integrado dentro del mismo proyecto:

  • Server Actions: Funciones fuertemente tipadas en el servidor para ejecutar transacciones de venta, descuentos de inventario y aperturas de caja sin necesidad de crear endpoints manuales redundantes.
  • Route Handlers (/api/...): Rutas REST dedicadas para recibir los webhooks de confirmación de Mercado Pago y peticiones de integración externa.
  • Validación Unificada con Zod: Un único archivo de validación para asegurar la integridad de precios, números de CUIT/DNI y campos obligatorios tanto en formularios del front como en el back.

C. Persistencia de Datos (PostgreSQL + Prisma)

  • PostgreSQL 16: Indispensable para transacciones financieras y de stock. Permite bloqueo de filas (Row-Level Locking con SELECT FOR UPDATE) para evitar que dos clientes (uno online y otro presencial) compren la última unidad en simultáneo.
  • Prisma ORM: Definición declarativa del modelo relacional, autocompletado en todo el código y migraciones de base de datos automatizadas.

3. Roadmap de Desarrollo Sugerido (Fases)

🔹 Sprint 1: Arquitectura Base y Modelo de Datos
Inicialización del repositorio TypeScript con Next.js 15, Tailwind y shadcn/ui. Definición del esquema Prisma (Tablas Product, ProductVariant, Stock, Category) y contenedor Docker de PostgreSQL.
🔹 Sprint 2: Módulo de Mostrador / POS (Caja Física)
Desarrollo de la pantalla de cobro rápido, soporte para lector de código de barras, cobro multimetodopago (Efectivo/Transferencia/QR), impresión de ticket y arqueo de caja diaria.
🔹 Sprint 3: Catálogo Web (E-commerce) y Checkout
Diseño del catálogo responsive, filtros por deportes y marcas, carrito de compras y checkout integrado con Mercado Pago.
🔹 Sprint 4: Sincronización, AFIP y Despliegue en VPS
Lógica de concurrencia atómica de stock, emisión de comprobantes fiscales con AFIP y despliegue del contenedor Docker en VPS con Caddy (SSL).

Inicializar componentes de UI shadcn pnpm dlx shadcn@latest init # 4. Instalar dependencias principales y ORM pnpm add @prisma/client mercadopago zod zustand dexie @tanstack/react-query lucide-react pnpm add -D prisma pnpm prisma init
